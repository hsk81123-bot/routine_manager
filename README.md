# 결 — 루틴 매니저

아이폰 화면에 맞춘 개인 루틴 관리 웹 앱입니다. 브라우저에 데이터가 저장되므로 별도의 가입이나 서버가 필요하지 않습니다.

## 실행

터미널에서 아래 명령을 실행한 뒤 표시되는 주소를 브라우저로 여세요.

```powershell
py -m http.server 8080
```

그다음 `http://localhost:8080`을 엽니다. 아이폰에서 사용하려면 이 프로젝트를 웹 호스팅 서비스에 올린 후 Safari의 **공유 → 홈 화면에 추가**를 선택하면 앱처럼 사용할 수 있습니다.

## 포함 기능

- 일간·주간·월간·연간 목표와 운동·음악·연구·개인 분류
- 오늘 할 일 추가 및 완료 여부 체크
- 기분 선택형 한 줄 일기와 최근 기록
- 이번 주 달성률과 회고 기록
- 브라우저 로컬 저장소 기반 자동 저장
